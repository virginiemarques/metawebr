# Metaweb <img src="man/figures/logo.png" align="right" width="120" />


Welcome to the page of the Metaweb package. Set of tools (functions) to help create a metaweb and compute indices of local networks. 

## Install

``` {r}
# Install remotes if you don't have it yet
# install.packages("remotes")
remotes::install_git("git@gitlab.ethz.ch:vmarques/metaweb.git")

library(Metaweb)
```
